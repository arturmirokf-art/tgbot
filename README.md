# NoHurtCam Telegram Bot

Telegram бот для управления HWID авторизацией и музыкальными событиями в NoHurtCam моде.

## 🚀 Быстрый старт

### Локальное тестирование:
```bash
npm install
npm test  # Проверка подключения
npm start # Запуск бота
```

### Деплой на Render.com:
1. Создайте GitHub репозиторий
2. Загрузите все файлы из этой папки
3. Подключите репозиторий к Render.com
4. Настройте переменные окружения
5. Деплой!

## 📋 Команды бота

- `/start` - Приветствие и список команд
- `/help` - Подробная помощь
- `/hwid_add <HWID>` - Добавить HWID в whitelist
- `/hwid_remove <HWID>` - Удалить HWID из whitelist
- `/hwid_list` - Показать все авторизованные HWID
- `/play_music` - Включить музыку RAKAI для всех пользователей
- `/stop_music` - Выключить музыку RAKAI
- `/stats` - Статистика сервера

## 🛠️ Troubleshooting

### Бот не отвечает:
1. Проверьте токен бота
2. Убедитесь что бот не заблокирован
3. Проверьте логи в Render панели

### Команды не работают:
1. Убедитесь что ваш User ID (7111158209) в списке админов
2. Проверьте подключение к серверу командой `/stats`

### Ошибки HWID:
1. Проверьте что сервер доступен
2. Убедитесь что ADMIN_KEY правильный
