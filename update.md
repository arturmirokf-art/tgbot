# Быстрое обновление бота

## 🔄 Обновление кода на GitHub

1. **Замените файлы в вашем репозитории:**
   - `bot.js` - исправлены ошибки Markdown и добавлен HTTP сервер
   - `package.json` - добавлена зависимость express

2. **Сделайте commit и push:**
   ```bash
   git add .
   git commit -m "Fix Markdown parsing and add HTTP server"
   git push
   ```

3. **Render автоматически переразвернет бота**

## ✅ Исправленные проблемы:

### 1. Ошибка парсинга Markdown:
- Убраны все `**bold**` и `\`code\`` символы
- Сообщения теперь отправляются как обычный текст
- Исправлена ошибка "can't parse entities"

### 2. Проблема с портом:
- Добавлен Express HTTP сервер
- Бот теперь слушает порт для Render.com
- Добавлены health check эндпоинты

### 3. Обновленные зависимости:
- Добавлен `express` для HTTP сервера
- Все зависимости актуальны

## 🧪 Тестирование:

После обновления:
1. Дождитесь завершения деплоя в Render
2. Откройте URL вашего сервиса - должна показаться JSON страница
3. Напишите боту `/start` - должно работать без ошибок
4. Попробуйте `/help` и `/stats`

## 🔧 Если проблемы остались:

1. **Проверьте логи в Render:**
   - Зайдите в панель Render
   - Откройте ваш сервис
   - Перейдите в "Logs"

2. **Проверьте переменные окружения:**
   - `BOT_TOKEN` должен быть правильным
   - `SERVER_URL` должен быть доступен
   - `ADMIN_KEY` должен совпадать с сервером

3. **Перезапустите сервис:**
   - В Render панели нажмите "Manual Deploy"
   - Или сделайте новый commit в GitHub
